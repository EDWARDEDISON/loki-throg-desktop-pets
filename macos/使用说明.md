# 洛基与雷神 · Mac 预览版 0.10.1

支持 macOS 11 及以上，同时包含 Apple 芯片与 Intel 架构。动画、音效和行为沿用 Windows v0.10；Mac 的菜单栏和窗口操作采用原生 AppKit。

## 使用

下载 LokiThrogPets-v0.10.1-macos-universal.zip，解压得到 LokiThrogPets.app。可以先把 App 拖入「应用程序」文件夹，再双击启动。无需安装 Python、Node 或其他运行环境。

菜单栏会出现 🐊🐸 图标，点开可设置声音、大小、暂停或退出。App 不显示 Dock 图标。

- 轻点角色：表情和声音回应。
- 按住并拖动角色：拎起，放下时有缓冲。
- 触控板两指点按 / 鼠标右键 / Control + 点击：单人动作、找对方互动、睡觉或醒来、设置。
- 独立巡游：到当前屏幕的远端后折返；碰面后 12 种互动等概率，未碰面时各自每 3～5 分钟可做单人表演。
- 声音默认开启、25% 音量，可调整和静音；设置保存在此 App 的 UserDefaults 中。
- 较小屏幕会限制显示倍数，确保完整双人动画能放下。

程序不联网、不设置开机启动。正常使用无需「辅助功能」或「屏幕录制」权限。

## 首次打开

这是尚未经过 Apple 开发者证书签名和公证的预览版本。首次从网络下载后，macOS 可能阻止打开。请先确认来源是本项目 GitHub Releases、核对 SHA256SUMS-macos.txt，再根据系统的「隐私与安全性」提示自行决定是否允许打开；不需要关闭 Gatekeeper 或其他系统防护。

此版本将由 GitHub macOS 环境进行编译和引擎自检。结果以随 Release 发布的验证日志为准。实际的不同显示器布局、Spaces、全屏应用及鼠标/触控板手感，还需要 Mac 使用者实机试用。
