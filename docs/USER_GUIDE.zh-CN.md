# 洛基与雷神 · Windows 像素桌宠 v0.10

## 开始运行

先从系统托盘退出正在运行的旧版，再运行本文件夹中的 LokiThrogPets.exe。请解压 ZIP 后运行。程序内嵌全部画面和音效，不需要安装 Python 或下载素材。

## 本次改进

**沿屏幕下方长距离巡游。** 旧版每走 4～10 秒就停步，下次随机选方向，所以常在附近往返。新版以当前屏幕工作区的远端为目标，到边缘再折返。途中每走约 18～30 秒可歇 0.7～1.8 秒，再沿原路线继续；互动结束后也保留尚未完成的目标。洛基速度为每秒 24 逻辑像素，雷神为 30，随显示倍数缩放。碰面、单人表演、菜单、睡觉和手动拖动仍会打断行走，所以不会要求每一趟都连续走完。拖到另一块屏幕后重新选当前屏幕的目标。

**雷神被拎起。** 左键按住并拖动超过约 5 像素后，进入专用动画：吃惊、蜷腿、交替蹬腿、挥动空着的手、放松悬空。保持一条披风和一把低持的锤子。按住期间循环，放下时屈膝缓冲，再恢复待机和自由活动。洛基原来的被拎动作保留。轻点和拖动已分开判断。

**短促街机音效。** 加入 14 种原创合成音效：蛙叫、回应、拎起、落下、比心、魔法、雷电、飞掠、水花、锤子落下、吃东西、小笑声、叮声、轻柔休息声。点击和拖动会回应；现有 36 组表演在关键时刻稀疏播放音效。行走不持续播放脚步声。

默认开启、音量 25%。右键角色 →「全局设置…」，或右键系统托盘图标，可以开关「播放像素音效」，选择 10 / 25 / 50 / 75 / 100% 音量，或试听蛙叫。音量仅作用于本程序；偏好保存到 %LOCALAPPDATA%\LokiThrogPets\sound-settings.ini，下一次启动沿用。播放失败时该次会话停止音效，动画仍可继续。暂停会停止当前音效，表演画面与声音触发点一起暂停。

## 原有行为

两只独立活动。轮廓靠近且地面高度相近时，自动从 12 种双人互动中等概率选择，每种 1/12，允许重复。结束后有 30 秒冷却。没有碰面时，各自每 3～5 分钟从自己的 12 种单人动作中等概率选择；忙于表演、被拖动、菜单展开或睡觉时延后。

右键某只角色可以点播它自己的单人动作，或让它主动去找哥哥 / 弟弟，进行随机或指定互动；也能睡觉、醒来、转身和回屏幕下方。托盘菜单保留自由移动、碰面互动、单人表演开关、大小、暂停和退出。

现有 24 组单人、12 组双人动画的画面原样保留，保持 24 帧/秒、2 像素逻辑网格；v9 修好的朝向、尾巴秋千和追尾巴也保留。

## 文件与验证

src/LokiThrogPets.cs 为源码，tools/build.ps1 用 Windows .NET Framework 编译，内嵌 454 张 PNG 和 14 段 WAV。sounds/ 中的音效由程序原创合成。docs/design/frog-pickup-keyposes-v10.png 是内置 image_gen 生成的补绘源图，提示词保存在 docs/design/frog-pickup-prompt-v10.txt；docs/design/new-assets-v10.json 记录统一调色与像素规格。docs/sound-cues.json 记录表演音效时刻。

实际运行 EXE 的 --self-test，通过 29,100 项断言，包括全部 8,736 帧、动作切换与结束、相遇和单人计时、1 倍和 2 倍下两只分别抵达屏幕两端、短歇后保留目标、手动转身、雷神悬空动画及落地、WAV 结构、关键帧音效触发一次、静音、音量限制、暂停及菜单保护。docs/validation/native-self-test-v10.txt 为日志。

正常运行 --smoke-test，创建原生透明窗口并完成 139 次刷新，一次蛙叫异步播放调用成功且无报错，详见 docs/validation/startup-check.txt。此前 36 张动画图集逐文件核对，和 v9 完全一致。没有更改系统安全设置；本轮没有逐项鼠标操作菜单的人工测试，实际听感可继续按你的反馈调整。

程序不联网，不设置开机启动。
