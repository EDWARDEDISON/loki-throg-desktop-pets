# 洛基与雷神 · Windows 像素桌宠 v0.10.0

鳄鱼洛基和青蛙雷神会在桌面上各自巡游，碰面后进行随机互动；也可以右键点播动作，让它主动去找哥哥 / 弟弟。

## 直接使用

下载本页 Assets 中的 **LokiThrogPets-v0.10.0-windows-x64.zip**，解压后双击 **LokiThrogPets.exe**。运行旧版时，请先从系统托盘退出旧版。GitHub 自动生成的 Source code 下载项是源码包。

本次更新：

- 巡游范围覆盖屏幕两端，短歇和互动后继续原路线。
- 雷神有完整的被拎起、蹬腿和落下反应。
- 14 种短促街机音效，默认音量 25%，可以静音并调音量。
- 保留全部 36 组已确认的像素动画。

程序不联网、不设置开机启动，无需安装 Python。当前在 Windows 11 上验证。EXE 尚未签名；如遇系统提示，请核对本仓库发布来源和附带的 SHA256SUMS.txt，不需要关闭系统防护。
