# 洛基与雷神 · Mac 通用预览版

现在可以在 Mac 上使用鳄鱼洛基与青蛙雷神桌宠了。一个包同时包含 **Apple 芯片（M 系列）和 Intel** 的原生程序，目标系统为 **macOS 11 及以上**。

## 下载和启动

下载本页 Assets 中的 **LokiThrogPets-v0.10.1-macos-universal.zip**，解压得到 **LokiThrogPets.app**，可以拖入「应用程序」后双击打开。无需安装 Python、Node 或其他运行环境。GitHub 自动生成的 Source code 是源码包。

- 顶部菜单栏 **🐊🐸**：声音、大小、暂停和退出。
- 轻点角色：回应；按住拖动：拎起和落下动作。
- 触控板两指点按 / 鼠标右键 / Control + 点击：单人动作、主动找对方互动、睡觉与醒来。
- 保留 36 组动作和 14 种音效、独立巡游、碰面等概率互动与 3～5 分钟单人表演。

## 首次打开的系统提示

这是使用 ad-hoc 签名检查完整性的预览包，尚未经过 Apple Developer ID 签名和公证。首次下载后，macOS 可能提示无法验证开发者或阻止启动。请先确认来源和 SHA256SUMS-macos.txt，再根据 [Apple 官方说明](https://support.apple.com/en-us/102445)由本人决定是否在「系统设置 → 隐私与安全性」中允许打开；无需关闭系统防护。

程序不联网、不设置开机启动，不需要辅助功能或屏幕录制权限。

## 验证与反馈

同一个通用包分别在 Apple 芯片和 Intel 的 macOS 15 runner 上执行：两边均通过全部 8,736 帧及行为自检、实际 AppKit 绘图对照、透明点击命中检查和原生窗口启动测试。验证记录随附 **Mac-validation-v0.10.1.zip**，构建过程见 [GitHub Actions](https://github.com/EDWARDEDISON/loki-throg-desktop-pets/actions/runs/39768216394)。

这是 Mac 首个预览版，仍需要不同用户机器上的显示器、Spaces、全屏应用、触控板与音频设备试用反馈。欢迎在 Issues 提供芯片、系统版本、缩放和复现步骤。

Windows 用户继续下载 v0.10.0 的 Windows 运行包；这一版不替换 Windows 稳定版。
